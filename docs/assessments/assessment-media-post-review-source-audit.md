## File consumer inventory

The inventory starts from each Prisma File relation and follows API writes,
historical reads, signed URL creation and raw content reads in the owning
modules. The retained-reference registry continues to own lifetime accounting.

| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

The shared predicate also protects the reserved object namespace.                                                                                      |

## Test and release evidence

The HTTP tests use owned PostgreSQL, MinIO and real request authorization.
They verify denial before signer or storage invocation for a pre-existing
ineligible record and confirm the legitimate generic and assessment byte
paths. GCS behavior is exercised through the actual adapter and a stateful SDK
double. Real GCS, capacity over the retention period and operational credentials
require a separately approved rehearsal. [Draft PR #237](https://github.com/Abdallah-Mohamed-Abdallah-AbdulRazzaq/Moazez-Backend/pull/237)
