# OR10 native XLSX transport

The XLSX adapter uses the same export selection, immutable artifact manifest, typed validation, review digest and sheet transaction as CSV. It produces typed string cells for operator-provided text and immutable identity values. Each workbook has an Instructions worksheet with status guidance and option codes. Data worksheets have protected identity columns, frozen headers and student columns, wrapped headings, filters and edit highlighting. Larger compatible workbooks include a navigation index. The application checks the manifest itself on upload.

The ZIP reader bounds compressed and expanded bytes, aggregate cell count, number of entries, per-entry expansion, and reads only the supported workbook parts. It verifies each entry's length and CRC. The XML parser streams UTF-8 into depth- and attribute-bounded handlers with DTDs disabled. It rejects formula and cached formula cells, unsupported cell types, links, macros, encrypted archives, protected workbook containers, unexpected populated tabs, and invalid paths. Internal worksheet relationships are resolved inside the archive. The parser never calculates a worksheet.

Excel and LibreOffice save the permitted open XML workbook using inline or shared strings. Reader acceptance remains limited to the exported worksheets, exact recorded identity values and normalized manual field commands. Formulas pasted into a grade cell invalidate the input. Values beginning with spreadsheet controls or a literal CSV escape prefix stay typed strings in XLSX. CSV continues to use its reversible text escape.
