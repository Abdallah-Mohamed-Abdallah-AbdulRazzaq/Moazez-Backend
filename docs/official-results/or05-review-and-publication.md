# OR05 review and publication

The release unit is one canonical slot and one definition release unit. Capture
freezes the values, source cell versions, calculations, academic attribution,
policy reference and release closure. The source fingerprint binds the fields
that affect that unit. An unrelated draft change does not supersede its approval.

An exact decision changes the candidate state and records an immutable decision.
The publishing command rechecks the candidate revision and digest, current
draft and policy, current actor, allocation, roster and prior publication
generation. Direct authorization records its own evidence without a reviewer
decision. The write updates the active composition and notification intent
together. A correction keeps the original publication in place until the exact
replacement is committed.

A changed release topology uses the dedicated school preview and confirmation.
The request binds every active publication, the explicitly preserved subset and
the approved replacement candidates. The transaction admits one disjoint
composition. Old snapshots and release events remain available for history.
