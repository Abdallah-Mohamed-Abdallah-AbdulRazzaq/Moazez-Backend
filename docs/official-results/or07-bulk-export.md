# OR07 export integration

The school and teacher preview routes bind the normalized selector, concrete sheets, selected field and slot IDs, definition and placement versions, policy, and exported typed values. The create command writes a durable queue intent after equality with the preview. The Core Worker rechecks the same fingerprint before writing files to private storage. Persisted file IDs and row IDs are reused during generation retries so a failed upload can be repeated with the same checksum.

Each file has a member export reference in the first CSV column. The API export ID identifies the job. The server resolves a member using both identifiers and the school, which also allows a user to upload one file from a heterogeneous download. The ZIP contains an index and instructions and is a download format.

The current SIS Student identity has no dedicated student-code field. The export displays the first 12 hexadecimal characters of the student UUID as a stable supplemental code. Import uses the opaque row reference and canonical linked IDs. The year-period value in the term column is YEAR_PERIOD.

Export READ_PUBLISHED projects active immutable release output values through the current staff and frozen field protection rules. The manifest records the publication IDs and labels the same columns read-only. Editable exports use manual fields with current read/edit access, including authorized, unaccepted teacher definitions in MANAGED mode. Closed-period export requires explicit slots and the same active release-unit correction window across the selected slots of each sheet. This keeps the frozen selection within the correction scope.

The private artifact registry is owned by Official Results. It stores the digest and manifest and uses a separate storage namespace. Result files do not receive general Files records or object URLs. Every download uses the current school and creator, concrete group/classroom authority, current field permissions, and member roster checks. An archived read uses the frozen release context. The API returns streamed bytes with private no-store and nosniff headers.

OR07 introduced a dedicated export job. OR12 routed that job through the existing files-imports Core consumer and its five-minute reconciliation trigger to preserve the Queue Redis budget in ADR-0008. Reconciliation scans bounded retry/expiry candidates, retries by the same deterministic queue ID, and removes failed or expired bytes while retaining outcome metadata. Media Worker ownership is unchanged.
