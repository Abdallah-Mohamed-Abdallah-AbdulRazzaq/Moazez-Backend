# OR11 period lifecycle and operational reports

The authorized staff reporting routes use the same current resource scope and field protection as the gradebook. The missing-grade report counts only visible required fields and separates missing values from placement reconciliation. Zero is recorded. History compares typed before/after values, identifies the effective definition and actor, and includes review and publication events and the caller's terminal import units. Family history uses the independent published-only projection.

Closing and archiving a period record an explicit reason and school-wide closure summary. Ordinary edits stop at ENTRY_CLOSED. Already frozen eligible candidates may finish review and publication until the period becomes ARCHIVED. Publication and audit history are retained. A named correction window provides time-limited authority for selected actors, slots and release units. A broad reopen needs a separate administrative decision, and an archived reopen needs both permissions and the exact reviewed impact. Archived windows are revoked on a period-wide transition so they cannot reopen incidentally.

Issue-report CSV files bind one immutable review and are stored in the private Official Results registry. Their application download is authenticated and rechecks that review's scope and fields. The raw upload is reachable only through its own reviewed source version. A file ID never enables the general Files subsystem to create a signed URL. Issue-report generation, reconciliation and retirement run on the Official Results bulk queue.

A publication outbox intent is recorded with the immutable result. The Core Worker rechecks that the release pointer is current, that the student/guardian link and membership are valid, and that the published audience contains a visible field. The current application notification feed receives a single in-app notice for each eligible recipient. The metadata contains the reporting period and an authenticated app destination. Grades, note bodies, and corrections are excluded from the message. Notice retries do not roll back the publication.
